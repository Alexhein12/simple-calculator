# Simple Calculator

A command-line calculator program built with Python that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division (with zero-division error handling)
- User-friendly menu interface
- Input validation

## Requirements

- Python 3.x
